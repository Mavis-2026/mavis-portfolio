### 2. 工具联通:3 个外部能力
| 能力 | 状态 | 怎么联通 |
|------|------|---------|
| **微信推送** | ✅ 原生 | MaxClaw 平台配置 webhook / 公众号 |
| **GitHub Actions 触发** | ⚠️ 用 HTTP/curl | 设置环境变量 `GITHUB_PAT` |
| **DeepSeek 推理** | ⚠️ 看你选 | 方案 A 直调 / 方案 B 走 GitHub |

### 3. 工作流:用户 → MaxClaw → GitHub → DeepSeek + 微信
```
[你] 跟 MaxClaw 说"看下盘"
   ↓

   ↓
[GitHub] 跑 workflow(用 v4-pro 调 DeepSeek)
   ↓
[微信] 收到推送
```
