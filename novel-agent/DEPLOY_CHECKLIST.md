### 节点 1:开始
- 接收用户输入（章节号、剧情要点）
- **输入变量**:
  - `chapter_no` (string) — 第几章
  - `plot_points` (string) — 剧情要点
  - `style` (string) — 风格（默认"起点男频"）

### 节点 2:LLM 节点（Kimi 写稿）
- **模型**:`kimi-k3`（或 `kimi-latest`）
- **输入**:从节点 1 接 + 系统 prompt
- **系统 prompt**:
```
你是网文作家。任务:写第 {chapter_no} 章。
剧情要点:{plot_points}
风格:{style}

要求:
1. 中文,3000-3500 字
2. 起点男频风格,爽点+悬念
3. 主角能动就动,别灌水
4. 结尾留钩子
```

- **模型**:`deepseek-chat`（默认）

```

1. 字数(目标 3000-3500)
2. 逻辑漏洞
3. 重复段落
4. 风格一致性
5. 给"通过/修改建议"
```
