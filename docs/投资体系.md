## 🎯 一、我的投资哲学

### 1. **大钱靠趋势,小钱靠波段**
- 我这次赌的是"AI 算力驱动的半导体超级周期"
- 周期长度:**2-3 年**
- 我的持仓周期:**半年到 1 年**
- 不做超短(没那个精力),不做超长(资金有成本)

### 2. **承认无知,相信逻辑**
- 我不知道"明天是涨是跌"
- 但我相信"半导体设备 8-12 月大概率向上"这个逻辑
- 逻辑不破,就拿着;逻辑破了,就撤
- **不预测,只应对**

### 3. **定力比聪明重要**
- 大部分人亏钱,不是因为看错了,是因为**拿不住**
- 涨了 20% 怕回调,跌了 10% 怕深套
- **我的反制:把规则写进代码,让系统提醒我**
- 不靠意志力,靠**纪律**

## 🧘 五、心理建设(关键!)

### 震荡期最容易犯的错
1. **"跌了就割"** → 卖在最低点,反弹拍大腿
2. **"涨了就追"** → 追在最高点,被套
3. **"天天看盘"** → 情绪被市场绑架
4. **"听消息"** → 利好出尽变利空

### 我的反制武器
1. **每天只看 1 次收盘价** → 不盯盘
2. **触发关键位才看新闻** → 不被噪音干扰
3. **写日记记录判断** → 复盘进步
4. **让 Mavis 提醒我** → 不靠意志力

### 8 月要告诉自己 3 句话
1. "**震荡是剧本内的事,我早就知道会这样**"
2. "**逻辑没破,拿着就是最好的操作**"
3. "**急跌到 0.65 才是机会,不是风险**"
