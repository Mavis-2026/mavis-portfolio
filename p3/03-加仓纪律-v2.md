# 加仓纪律 v2(信号确认 + 逻辑重置)

> 取代旧的"公式法"(-20% 加仓 / -30% 止损)
> 最后更新:2026-07-29
> 适用账户:主账户 8335 / 副账户 7661(独立执行)

---

## 一、为什么改

**旧公式**:
- 跌 -20% 加仓 1 万
- 跌 -30% 止损

**问题**:
1. **公式假设价格会反弹**,但可能逻辑已变
2. **跌完加仓 = 越跌越买**,加完到 -30% 止损时,亏得更多
3. **没确认就加仓**,可能抄在半山腰

**新思路**:**跌多了不是加仓的理由,逻辑没变才是**。

---

## 二、新纪律总览(3 + 4 组合)

**3 = 信号确认法**:加仓前必须有 2-3 个确认信号
**4 = 逻辑重置法**:每次跌到加仓位时,先重新评估核心逻辑

### 加仓决策流程

```
价格跌到加仓观察位
    ↓
【第 1 步】逻辑重置:核心逻辑变了吗?
    ├─ 是 → 不加仓,反手考虑减仓
    └─ 否 → 进入第 2 步
    ↓
【第 2 步】信号确认:有 2-3 个企稳信号吗?
    ├─ 否 → 继续观察,不加仓
    └─ 是 → 进入第 3 步
    ↓
【第 3 步】分批加仓
```

## 五、信号满足度的加仓金额

**基础原则**:信号越强,加仓越多;信号越弱,加仓越少

| 信号满足度 | 加仓金额 | 仓位变化 |
|----------|---------|---------|
| 5 个信号全满足(强信号) | 2.0 万 | 主仓 22.7% → 27.5% |
| 3-4 个信号(中信号) | 1.0 万 | 主仓 22.7% → 24.5% |
| 仅 2 个信号(弱信号) | 0.5 万 | 主仓 22.7% → 23.4% |
| 不足 2 个信号 | **不加仓** | 不变 |

**最大加仓上限**:即使信号齐了,单次加仓不超过 ¥3 万(避免单押过重)

## 六、逻辑重置:每次必答 5 个问题

**跌到加仓位时,先答这 5 个问题,任一答案为"否"就不加**:

1. **核心逻辑还在吗?**
   - 国产替代 + AI 需求 = 159516 的核心逻辑
   - 任何一项**根本性、不可逆**的改变 → 不加

2. **行业在变吗?**
   - 不是"短期波动",是"结构性变化"
   - 例:AI 算力需求见顶 / 国产替代被打破 / 政策逆转

3. **我的仓位合理吗?**
   - 主账户 98.5% 满仓 = 不合理(没空间加仓)
   - 主账户 70% 以下 = 合理(有空间加)
   - 主账户 80-95% = 谨慎(加要分小批)

4. **我的钱是闲钱吗?**
   - 是 → 跌了不慌,可以扛
   - 否(房贷/应急) → 慎加,优先保流动性

5. **我能接受再跌 10% 吗?**
   - 加完仓后,如果再跌 10%(0.65 → 0.585),我扛得住吗
   - 心理上扛不住 → 不加

**5 题全答"是"才进入信号确认环节**。

## 七、止损纪律(没变,但跟加仓解耦)

**新止损规则**:**不跟加仓位挂钩,跟逻辑挂钩**

| 触发条件 | 操作 |
|---------|------|
| 核心逻辑变(国产替代破 / AI 故事讲不下去) | **立即清仓,不论价格** |
| 跌破 0.576(趋势走坏位 0.72×0.8) | **强制清仓** |
| 跌破 0.605(-30% 止损) | **最后防线,减仓 1/2** |
| 跌破 0.630(双底支撑) | **暂停所有加仓,重新评估** |

**关键**:**止损位是死的,但触发条件是"逻辑/趋势"** — 不到那个位不触发,到了无条件执行。

## 八、实战示例(159516 现状)

### 当前(2026-07-29 收盘)

- 成本 0.864
- 现价 0.706
- 浮亏 -18.28%
- 距 **0.778 (-10% 加仓位)** 差 0.072(已破位 9.3%)
- 距 0.691 还差 0.015(2.2%)

### 案例 A:7-28 跌到 0.720(-16.7%,已破 -10% 加仓位)

**第 1 步 - 逻辑重置**:
1. 国产替代逻辑?——**还在**(中芯/华虹扩产 + 大基金三期)✓
2. AI 需求?——**还在**(全球 capex 持续 + 长鑫 IPO)✓
3. 我的仓位?——**不合理,98.5% 满仓** ✗
4. 闲钱?——是 ✓
5. 再跌 10% 扛得住?——心理上**不确定** ✗

→ **第 3、5 题没答"是"** → **第 1 步不通过 → 不加仓**

### 案例 B:7-29 跌到 0.706(-18.3%,继续破 -20% 加仓位)

**第 1 步 - 逻辑重置**:
- 答案跟 7-28 类似:逻辑还在,但仓位 98.5% 满仓
- **第 3 题仍未通过 → 不加仓**

**结论**:**虽然 7-28 和 7-29 都触发加仓价位,但 3+4 组合验证 → 不加仓**

→ **3+4 组合成功阻止了"抄底式加仓"** — 这就是新纪律的价值

### 案例 C:如果将来出现以下情况,可以加仓

**触发条件**(全部满足):
1. 价格跌到 0.778(-10%)或更低 ✓
2. **第 1 步 5 题全答"是"**(尤其第 3 题仓位必须降到 80% 以下)
3. **第 2 步 满足 2-3 个企稳信号**

### 案例 D:如果跌到 0.605(-30% 止损线)

**第 1 步**:
- 逻辑还在?——**看长鑫 IPO 进展 + 大基金动作**
- 仓位?——同样问题
- 心理?——**很可能扛不住**

→ **多数情况第 5 题扛不住 → 减仓 1/2(不全部清仓)**
→ 如果**逻辑变了** → **清仓**

### 案例 E:如果跌到 0.576(趋势走坏位)

**无条件清仓,不验证任何信号** — 死纪律

## 九、3+4 组合 vs 旧公式的对比

| 情景 | 旧公式(-20% 加仓) | 新纪律(3+4 组合) |
|------|-------------------|-------------------|
| 7-28 跌到 0.720 | ❌ 没触发(-16.7%) | ❌ 不加(仓位满) |
| 7-29 跌到 0.706 | ✅ 触发,加 1 万 | ❌ 不加(仓位满) |
| 跌到 0.650 | ❌ 还没到 | ❌ 3 题没答齐不加 |
| 跌到 0.605 | ❌ 还没到 -30% | ⚠️ 减仓 1/2 |
| 跌到 0.576 | ❌ 还没到 | 🛑 无条件清仓 |

**关键**:**3+4 组合的关键是"早加 + 严验证"** — 价格触发就检查,不机械等 -20% / -30%。

## 九、什么时候破纪律都不行

**这 3 个位是死线,破了无条件操作**:

1. **0.576 趋势走坏位** — 跌破**立即清仓**(不论逻辑)
2. **核心逻辑根本性变化** — 立即清仓(不论价格)
3. **0.605 -30% 止损位** — **减仓 1/2**(不是全清,是降风险)

**这 3 个位 = "逃生通道"** — 不依赖信号,不依赖判断,机械执行。

## 总结:从公式法到纪律法

| 维度 | 旧公式 | 新纪律 |
|------|--------|--------|
| 加仓触发 | **跌 20%** | **跌 10%** + 信号确认 + 逻辑重置 |
| 决策依赖 | 价格数字 | 信号 + 逻辑 + 心理 |
| 加仓金额 | 固定 1 万 | 按信号强度 0.5-2 万 |
| 止损触发 | -30% 机械 | 趋势走坏 + 逻辑变化 |
| 心理作用 | 公式让你不用想 | 纪律让你必须想 |
| 抗跌能力 | 弱(越跌越加) | 强(只加真企稳) |

**3+4 组合 = "早触发 + 严验证"**:
- **-10%** 比 -20% 早 2 步触发 → 有空间验证,不靠"赌"
- 5 题逻辑重置 + 2-3 个信号 → 严格把关
- 加仓金额看信号强度 → 谨慎加仓

**一句话**:**从"机械执行"升级为"判断决策"**。
