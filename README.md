# Mavis 投资助理 - 项目说明

> 你的 7×24 自动化投资盯盘系统
> 首次搭建:2026-07-23
> 搭建者:Mavis(用户)+ Mavis(AI 助理)

---

## 🎯 系统目标

为个人投资者提供**半自动化的投资监控 + 决策支持**:
- ✅ 实时监控持仓价格、板块走势
- ✅ 智能判断关键位(止损/加仓/止盈)
- ✅ 自动抓取板块相关新闻
- ✅ 多渠道推送(钉钉群机器人)
- ✅ 每日完整复盘报告
- ⏸️ 决策由人做出(保留判断空间)

**定位**:不是量化(全自动交易),而是**AI 增强的智能投顾助理**。

## 🚀 快速开始

### 查看今日复盘报告
```bash
# 打开 HTML 报告(可视化)
open /workspace/reports/daily-review-$(date +%Y-%m-%d).html

# 查看 Markdown 报告(手机看)
cat /workspace/reports/daily-review-$(date +%Y-%m-%d).md
```

### 手动触发盘中监控
```bash
python3 /workspace/scripts/intraday_monitor.py
```

### 手动触发收盘报告
```bash
python3 /workspace/scripts/daily_review.py
```

### 测试钉钉推送
```bash
python3 /workspace/scripts/dingding_sender.py test
```

## 🔧 维护指南

### 修改持仓
编辑 `/workspace/portfolio/holdings.json`,然后重新运行报告。

### 修改钉钉配置
编辑 `/workspace/config/dingding.json`(注意保密!)

### 修改关键位
编辑 `/workspace/scripts/intraday_monitor.py` 中的 `KEY_LEVELS` 字典。

### 修改推送时间
使用 `mavis cron` 命令查看/修改定时任务。

### 数据备份
所有文件都在 `/workspace/`,重要文件建议每周备份到本地。

## ⚠️ 重要说明

1. **这不是投资建议**——系统只提供信息和提醒,所有决策由用户做出
2. **数据可能有延迟**——新浪 API 通常延迟 < 5 分钟,紧急决策请以券商 APP 为准
3. **关键位是参考**——不是死规则,具体操作要结合市场环境
4. **数据源**:新浪财经(免费公开 API)、新闻(新浪快讯)
5. **推送通道**:钉钉群机器人(加签模式,需保密 webhook URL)
6. **成本**:完全免费,无任何付费服务
